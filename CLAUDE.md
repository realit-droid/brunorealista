## Como trabalhamos

- **Vibecoding**: Eu (Realista) oriento, reviso e testo o código gerado por ti — não escrevo Python ou JavaScript de forma independente. HTML, CSS e PHP são áreas onde tenho conhecimento próprio e maior autonomia.
- **Ritmo**: Metódico e deliberado. Uma secção/alteração de cada vez. Nunca despejes várias opções ou passos de uma vez — avança passo a passo e confirma comigo antes de continuares para o seguinte.
- **Alterações a ficheiros/documentos**: Propõe sempre a alteração primeiro e espera a minha confirmação explícita antes de aplicares. Nunca proponhas e apliques ao mesmo tempo.
- **Honestidade técnica**: Nunca digas que "eu programo em Python" ou "eu desenvolvo em JavaScript" em texto dirigido a mim ou gerado para mim (CVs, LinkedIn, documentação) — o correto é "vibecoding com apoio de IA", já que reviso e testo mas não domino a linguagem de forma independente.
- **Idioma**: Português europeu, salvo se eu escrever em inglês.
- **Aprendizagem**: Aprendo melhor praticando do que lendo — prefiro experimentar e corrigir do que explicações longas antes de agir.

## Sobre este projeto

Página pessoal (`brunorealista.com`) com várias secções:

- **Ator** — referências/portefólio como ator.
- **Fotógrafo** — portefólio de fotografia.
- **Programador** — inclui uma secção de **Projetos**, onde entra um cartão/link
  para o [Realista Investimentos](../realista-investimentos) (ferramenta de
  análise de negócios imobiliários) — visível publicamente como divulgação,
  mas o acesso à aplicação em si fica protegido por login (email/password)
  dentro dessa outra app, não aqui.

Este site em si é **público, sem login nenhum** — a proteção existe só dentro
da aplicação de investimentos, que é um projeto totalmente à parte.
